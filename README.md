# 🏗️ BuildCost — Construction Cost Estimator

BuildCost is a Python/Streamlit web application for creating preliminary construction cost estimates. It lets users edit project quantities and unit prices, apply contingency/overhead/profit, visualize costs by category, and export estimate data.

## Features
- Editable construction estimate table
- Earthwork, concrete, paving, utilities, and site-work examples
- Automatic quantity × unit-cost calculations
- Contingency, overhead, and profit markups
- Project cost dashboard
- Interactive category chart
- CSV export
- Responsive browser-based UI

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy as a website
1. Create a GitHub repository and upload these files.
2. Sign in to Streamlit Community Cloud with GitHub.
3. Select the repository and `app.py` as the entry point.
4. Deploy. Streamlit will provide a public website URL.

## Disclaimer
This application is intended for preliminary estimating and educational/portfolio use. Actual construction pricing varies by project scope, location, market conditions, contractor, and date.
